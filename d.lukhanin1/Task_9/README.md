# Задание 9. Создание двух процессов

`fork()` создаёт потомка, который запускает `cat` через `execlp()` и печатает переданный файл. Родитель выводит сообщение через `printf()`, сбрасывает буфер stdout и ожидает именно этого потомка через `waitpid()`. Прерванное сигналом ожидание повторяется. Строка `Parent: child finished.` печатается только после завершения потомка, в том числе при ошибке `cat`.

Сборка и запуск из этой папки:

```sh
make
seq 1 10000 > /tmp/task9-long.txt
./child_cat /tmp/task9-long.txt
```

Проверка: все числа должны появиться в выводе, последней строкой должна быть `Parent: child finished.`. Первое сообщение родителя может появиться до или во время вывода `cat`. Для файла без завершающего перевода строки последнее сообщение может продолжить его строку, но всё равно выводится после `cat`. Имя файла обязательно; отсутствующий файл или ошибка запуска/ожидания дают ненулевой код программы.

Автоматическая проверка заданий 9, 10 и 25 из этой папки:

```sh
python3 ../test_process_pipe.py
```

`make clean` удаляет исполняемый файл.
