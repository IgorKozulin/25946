# Следующая сдача по операционным системам

По актуальному файлу преподавателя `Задания.txt` в ветке `upstream/main`
срок следующего набора — **19 ноября 2026 года**. Нужны **9, 10, 17, 18, 21, 25**.
Задача 11 в этот набор не входит. Наличие исходников не означает, что
преподаватель уже принял работу: это проверяется отдельно по журналу.

Решения написаны на C, в каждой папке есть Makefile, исходное условие и README.
Ниже команды для локального запуска из корня репозитория.

## 9 — создание двух процессов

```sh
make -C d.lukhanin1/Task_9
seq 1 100 > /tmp/os-long-file.txt
./d.lukhanin1/Task_9/child_cat /tmp/os-long-file.txt
```

Дочерний процесс заменяет себя командой `cat` через `exec`. Родитель ждёт
его через `waitpid`, поэтому последняя строка родителя появляется после файла.
На сдаче объясни отличия родителя и ребёнка по результату `fork`.

## 10 — код завершения команды

```sh
make -C d.lukhanin1/Task_10
./d.lukhanin1/Task_10/run_command sh -c 'exit 7'
```

Программа создаёт процесс для произвольной команды, передаёт ей аргументы,
ждёт завершения и показывает код 7. На сдаче объясни, почему значение `status`
от `waitpid` нужно разбирать через `WIFEXITED` и `WEXITSTATUS`, а не печатать напрямую.

## 17 — строчный редактор

```sh
make -C d.lukhanin1/Task_17
./d.lukhanin1/Task_17/line_editor
```

Запускай в настоящем терминале. Проверь обычный ввод, Backspace, Ctrl-U
(обычный KILL), Ctrl-W, перенос слова за 40-й столбец и Ctrl-D в пустой строке.
На сдаче объясни `ICANON`, `ECHO`, собственное хранение строки и восстановление
настроек терминала. Конкретные ERASE/KILL определяются настройками `stty -a`.

## 18 — информация о файлах

```sh
make -C d.lukhanin1/Task_18
./d.lukhanin1/Task_18/file_listing d.lukhanin1/Task_18 d.lukhanin1/Task_18/Makefile
ls -ld d.lukhanin1/Task_18 d.lukhanin1/Task_18/Makefile
```

Для каждого аргумента выводятся тип, права, количество связей, владелец,
группа, размер обычного файла, время изменения и имя без пути. У каталогов
поле размера пустое согласно условию. На сдаче объясни `lstat`, биты прав,
`getpwuid`, `getgrgid` и `mtime`.

## 21 — пищалка

```sh
make -C d.lukhanin1/Task_21
./d.lukhanin1/Task_21/beeper
```

Ctrl-C вызывает звуковой сигнал, Ctrl-\ выводит счётчик и завершает программу.
Терминал может показывать визуальное уведомление вместо звука или отключать
звонок настройками. На сдаче объясни `SIGINT`, `SIGQUIT` и собственную обработку
сигналов вместо стандартного завершения процесса.

## 25 — связь через канал

```sh
make -C d.lukhanin1/Task_25
printf 'Hello, Operating Systems!\n' | ./d.lukhanin1/Task_25/pipe_upper
```

Один процесс посылает текст в `pipe`, второй читает и переводит буквы
в верхний регистр. Результат: `HELLO, OPERATING SYSTEMS!`.
На сдаче объясни два дескриптора канала, `fork` и необходимость закрыть
неиспользуемые концы: без закрытия пишущих концов читатель не получит EOF.
