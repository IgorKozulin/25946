# Задание 21. Пищалка

`beeper` ожидает сигналы: каждый принятый `SIGINT` выводит символ BEL (`\a`),
а `SIGQUIT` печатает число сигналов и завершает программу с кодом 0.
Первоначальное условие сохранено в `Task_21.txt` без методических дополнений.

## Решение

Перед сообщением о готовности программа блокирует `SIGINT` и `SIGQUIT`
через `sigprocmask`, затем ожидает их с помощью `sigwait` в бесконечном цикле.
Сигнал, пришедший между двумя ожиданиями, остаётся ожидающим и будет принят
при следующем вызове. Процесс спит в ожидании сигнала и не занимает процессор
пустым циклом.

После `SIGINT` программа записывает один байт BEL через `write` и увеличивает
счётчик. При `SIGQUIT` итог выводится обычным `printf` из основного потока.
Обработчики сигналов не устанавливаются, поэтому небезопасных вызовов stdio
из обработчика нет. Настройки терминала не изменяются. Маска сигналов
действует только в этом процессе и исчезает при его завершении.

Обычные сигналы POSIX не образуют очередь: несколько одинаковых сигналов,
пришедших до принятия предыдущего, могут объединиться в один. Подсчитываются
принятые `SIGINT`, а не гарантированно все быстрые нажатия клавиш. При ошибке
системного вызова или вывода программа сообщает об ошибке в stderr и
возвращает 1.

## Сборка и запуск

Нужны POSIX-система, компилятор C11 и `make`. Сборка использует
`_POSIX_C_SOURCE=200809L` и `_FILE_OFFSET_BITS=64`, без сторонних библиотек.

```sh
make
./beeper
```

После сообщения о готовности нажмите Ctrl+C несколько раз, затем Ctrl+\.
Комбинации соответствуют обычным настройкам терминала; их можно посмотреть
через `stty -a`. Реальный звук зависит от поддержки BEL и настроек терминала.
Без терминала можно посылать `kill -INT PID` и `kill -QUIT PID` из другого
окна, подставив идентификатор процесса.

```sh
make clean
```

```sh
make check
```

Python 3 запускает настоящий дочерний процесс. Тесты ждут сообщения о
готовности, посылают четыре `SIGINT`, дожидаясь каждого байта BEL, затем
проверяют итог после `SIGQUIT`. Отдельно проверяется выход со счётчиком 0.
