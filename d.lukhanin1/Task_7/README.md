# Задача 7 — поиск строки через mmap

Поведение задачи 6 сохранено: номер строки, 0 для выхода, по 5 секунд на каждый
запрос и полный вывод файла при таймауте. Доступ к содержимому файла заменён
отображением в память. Прямых вызовов `read`, `lseek` и `write` в исходнике нет.

## Сборка и запуск

```sh
cd ~/25946/d.lukhanin1/Task_7
make
./line_lookup_mmap test.txt --table
```

Введите `4` и Enter, затем `0` и Enter. Для таймаута запустите снова и
подождите пять секунд без ввода. Для быстрой проверки:

```sh
printf '4\n1\n0\n' | ./line_lookup_mmap test.txt
```

## Как устроено отображение

`open` открывает файл, `fstat` получает размер через `st_size`. `map_file`
проверяет обычный файл и вызывает:

```c
mmap(NULL, size, PROT_READ, MAP_PRIVATE, fd, 0)
```

`NULL` позволяет ядру выбрать адрес. `PROT_READ` разрешает чтение.
`MAP_PRIVATE` создаёт частное отображение; программа файл не изменяет.
Последний аргумент 0 означает начало файла. Ошибка обозначается `MAP_FAILED`.

`mapping.data` указывает на первый байт файла, `mapping.size` хранит размер.
После успешного отображения `close(fd)` допустим: область памяти продолжает
существовать. Программа не читает весь файл предварительно через `read`;
ядро обеспечивает доступ к страницам при обращениях к отображению.

`build_table` проходит по `mapping.data[i]`. Каждый `\n` завершает строку,
для которой записываются смещение и длина. Для выбранной строки адрес равен
`mapping.data + offset`. `fwrite` выводит точно `length` байт. Добавлять `\0`
в отображение нельзя и не нужно: оно доступно только для чтения, а строки
внутри него не обязаны заканчиваться нулевым байтом.

При таймауте `fwrite(mapping.data, 1, mapping.size, stdout)` печатает весь файл.
В конце `free` освобождает таблицу, `munmap` снимает отображение. Пустой файл
обрабатывается отдельно: `mmap` с нулевой длиной не вызывается.

## Что объяснить на сдаче

- В задаче 5 `lseek` выбирает позицию и `read` копирует текст в буфер программы.
- Здесь позицию задаёт арифметика указателей, а данные предоставляет отображение.
- Адрес начала отображения и размер нужны для последующего `munmap`.
- Закрытие дескриптора и удаление отображения — разные действия.
- `fwrite` — библиотечная функция; внутри libc возможен `write` для вывода на экран.
  Условие заменяет файловый доступ, а не запрещает ядру обслуживать stdout или stdin.
- Рабочий файл не должен обрезаться или изменяться другим процессом во время работы:
  обращение к странице за новым концом файла может вызвать `SIGBUS`.
- Таймер и сигналы разобраны в [задаче 6](../Task_6/README.md), таблица — в [задаче 5](../Task_5/README.md).
