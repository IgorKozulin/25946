# Задание 18. Листинг файлов

`file_listing` выводит сведения о каждом переданном пути, подобно `ls -ld`.
Каталоги не обходятся. Без аргументов выводится текущий каталог `.`.
Первоначальное условие сохранено в `Task_18.txt`; дополнительные методические
материалы из общего задания в этот файл не включены.

## Решение

Для получения метаданных используется `lstat`: символическая ссылка описывается
сама, без перехода к цели. Тип обозначается `d` для каталога, `-` для обычного
файла и `?` для остальных объектов. Следующие девять символов показывают биты
`rwx` владельца, группы и остальных пользователей. Специальные биты
setuid/setgid/sticky не заменяют символ `x`, поскольку условие требует только
три базовых права доступа.

Далее выводятся число жёстких ссылок, владелец, группа, размер, время изменения
и имя без пути. Имена ищутся через `getpwuid` и `getgrgid`; если записи нет,
выводится числовой идентификатор. Размер в байтах показывается только для
обычных файлов. Время берётся из `st_mtime`, переводится в местное время и
выводится в формате `YYYY-MM-DD HH:MM`. Конечные `/` удаляются перед обработкой
пути, кроме единственного `/`, обозначающего корень.

Столбцы имеют минимальные ширины: число ссылок — 5, владелец и группа — по 16,
размер — 12 символов. Длинные значения печатаются целиком, расширяя поле.
Операнды обрабатываются в исходном порядке; имена, начинающиеся с `-`, также
считаются путями. При ошибке сообщение идёт в stderr, остальные аргументы
обрабатываются, код завершения равен 1. При успехе код равен 0.

## Сборка и запуск

Нужны POSIX-система, компилятор C11 и `make`. Настройки сборки включают
`_POSIX_C_SOURCE=200809L` и `_FILE_OFFSET_BITS=64`; сторонних библиотек нет.

```sh
make
./file_listing /etc/passwd /tmp /dev/null
./file_listing .
make clean
```

Пути с пробелами следует заключать в кавычки.

## Проверка

Из каталога задания:

```sh
make check
```

Тесты требуют Python 3 и используют настоящие временные файлы, жёсткую и
символическую ссылки, каталог и FIFO. Проверяются права, владелец, группа,
размер, время, выравнивание, имена, обработка отсутствующего файла и запуск
без аргументов. Общий запуск обеих групп проверок из `d.lukhanin1`:

```sh
python3 test_listing_signal.py
```
