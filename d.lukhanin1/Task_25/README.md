# Задание 25. Связь через программный канал

Программа создаёт `pipe()` и вызывает `fork()`. Родитель читает stdin блоками и полностью записывает каждый блок в канал. Потомок читает канал, применяет `toupper((unsigned char)...)` к каждому байту и полностью записывает результат в stdout. Неиспользуемые концы канала закрываются сразу. После EOF родитель закрывает конец записи и ожидает потомка через `waitpid()`.

Чтение, запись и ожидание повторяются при `EINTR`; короткая запись дописывается циклом. Пустые строки и нулевые байты передаются как обычные данные. `SIGPIPE` игнорируется, чтобы обработать ошибку записи и дождаться потомка. Ошибки ввода, вывода, создания процессов и неуспешное завершение потомка дают ненулевой код программы.

Сборка и проверка из этой папки:

```sh
make
printf 'Hello, WoRlD!\n\nnext line\n' | ./pipe_upper
printf '' | ./pipe_upper
./pipe_upper
```

Первый запуск выводит `HELLO, WORLD!`, пустую строку и `NEXT LINE`. Второй ничего не выводит и завершается. В интерактивном запуске ввод завершается Ctrl+D на пустой строке; сама пустая строка программу не останавливает. Обработка побайтовая в стандартной C locale: латинские ASCII-буквы переводятся в верхний регистр, UTF-8 кириллица не преобразуется.

```sh
python3 ../test_process_pipe.py

```
