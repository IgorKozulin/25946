# Задание 10. Код завершения команды

Родитель создаёт потомка через `fork()`. Потомок вызывает `execvp(argv[1], argv + 1)`: имя команды ищется в `PATH`, остальные аргументы передаются без изменений. Родитель ожидает потомка через `waitpid()`, повторяя ожидание при `EINTR`, и печатает `Exit status: N` при обычном завершении либо `Signal: N` при завершении сигналом. При ошибке `execvp()` потомок пишет диагностику в stderr и завершается с кодом 127.

Сборка и проверка из этой папки:

```sh
make
./run_command printf '%s\n' 'Hello world'
./run_command sh -c 'exit 37'
./run_command sh -c 'kill -TERM $$'
./run_command missing-command-for-os-task-25946
```

После `Hello world` ожидается `Exit status: 0`, далее соответственно `Exit status: 37`, `Signal: 15` и `Exit status: 127` с диагностикой в stderr. Кавычки обрабатывает вызывающая оболочка: сама программа не разбивает аргументы и не выполняет shell-подстановки.

Собственный код программы равен 0, если команда запущена либо ошибка запуска зафиксирована потомком, ожидание и печать статуса выполнены успешно. Он не копирует код команды; ненулевой код означает ошибку самой обёртки или отсутствие команды в аргументах.

```sh
python3 ../test_process_pipe.py

```
