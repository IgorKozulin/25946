# Задача 5 — поиск строки по номеру

Программа один раз строит таблицу смещений и длин строк текстового файла.
Затем по номеру читает и печатает только выбранную строку. Нумерация начинается
с 1; номер 0 завершает программу. После каждой выбранной строки выводится её
размер в байтах. При запуске выводится сумма размеров всех строк файла.

## Сборка и запуск

```sh
cd ~/25946/d.lukhanin1/Task_5
make
./line_lookup test.txt --table
```

`--table` — необязательный вывод таблицы для проверки. Для приложенного файла:

```text
Line 1: offset=0 length=11
Line 2: offset=11 length=12
Line 3: offset=23 length=1
Line 4: offset=24 length=9
Total size: 33 bytes
```

В строке 3 находится только `\n`. Последняя строка — `Last line` без `\n`.
Введите `2`, затем `4`, затем `0`: получите `Second line` и `Last line`.

```sh
printf '2\n4\n0\n' | ./line_lookup test.txt
```

Подсказки и ошибки печатаются в stderr; строки файла и таблица — в stdout.

Размер строки включает сохранённый в файле перевод строки `\n`, но не включает
добавленный программой завершающий `\0` или перевод строки для оформления вывода.
Для `test.txt` сумма равна `11 + 12 + 1 + 9 = 33` байтам. Повторный запрос одной
строки не меняет общую сумму. Для точного сравнения используй `ls -l test.txt`
или `wc -c < test.txt`. `ls -lh test.txt` показывает тот же размер в удобных
единицах и может округлять его.

## Как устроен код

`open(FILE, O_RDONLY)` возвращает файловый дескриптор. Это целое число,
через которое `read`, `lseek` и `close` обращаются к открытому файлу.

`struct Line` хранит `off_t offset` и `size_t length`. Смещение — число байт
от начала файла, длина — число байт строки вместе с `\n`, если он есть.
У первой строки смещение 0. У UTF-8 букв может быть несколько байт: таблица
считает байты, а не буквы.

`build_table` читает блоки по 4096 байт. `lseek(fd, 0L, SEEK_CUR)` получает
текущую позицию после блока. `SEEK_CUR` — символическое имя значения 1 из
условия. По позиции конца блока вычисляется позиция каждого найденного `\n`.
`add_line` записывает начало и длину завершённой строки. Если в конце остались
байты без `\n`, они образуют последнюю строку. Дополнительная пустая строка
после конечного `\n` не создаётся. Для пустого файла таблица пуста.

`struct Table` хранит динамический массив записей, число строк `count` и
вместимость `capacity`. `realloc` расширяет массив при заполнении. Текст всего
файла в памяти не хранится: только таблица и текущая выбранная строка.

После ввода номера `print_line` вызывает `lseek(fd, offset, SEEK_SET)`,
выделяет `length + 1` байт и читает ровно `length` байт. Один `read` может
вернуть меньше запрошенного: цикл дочитывает остаток. После текста добавляется
`\0`, поэтому его можно вывести через `printf("%s", text)`.

`read_query` получает целую строку ввода. `parse_number` проверяет число через
`strtoumax`: отрицательные значения, мусор, переполнение и номера вне таблицы
не приводят к обращению за границы массива. Следующий запрос остаётся доступен.
В конце освобождается таблица и вызывается `close(fd)`.

## Что объяснить на сдаче

- Таблица позволяет после одного прохода находить начало любой строки без повторного поиска.
- `SEEK_SET` отсчитывает позицию от начала файла, `SEEK_CUR` — от текущей позиции.
- Пользователь вводит номер от 1, а индекс массива равен `number - 1`.
- `read` не добавляет `\0`; программа добавляет его сама перед `printf`.
- Если строка не заканчивается `\n`, при отдельном выводе добавляется перевод строки для удобства.
- Файл предполагается текстовым, без встроенных нулевых байтов, и не меняется во время работы.
