# Задание 17. Строчный редактор

Программа читает клавиатуру по одному байту и сама выводит введённые символы. Для этого она сохраняет настройки терминала через `tcgetattr`, отключает `ECHO`, `ICANON`, `IEXTEN` и `ISIG`, устанавливает `VMIN = 1`, `VTIME = 0`. Перед завершением исходные настройки восстанавливаются через `tcsetattr`. Ввод и вывод должны быть подключены к терминалу.

## Сборка и запуск

Из корня репозитория:

```sh
cd d.lukhanin1/Task_17
make
./line_editor
```

Для сборки нужны C-компилятор и `make`. Применяются C11 и POSIX; дополнительных библиотек нет. Параметры компилятора такие же, как в предыдущих заданиях. Например, можно выбрать другой компилятор командой `make CC=cc`.

## Клавиши

- Печатные ASCII-символы появляются сразу.
- `ERASE` стирает последний символ текущей строки. Обычно это Backspace или Delete; программа берёт реальный код из `c_cc[VERASE]` сохранённых настроек.
- `KILL` очищает текущую строку. Обычно это Ctrl+U; код берётся из `c_cc[VKILL]`.
- Ctrl+W удаляет пробелы в конце строки, затем последнее слово. Пробел перед этим словом остаётся: в `one two   ` останется `one `.
- Enter начинает пустую строку.
- Ctrl+D завершает программу, когда текущая строка пуста. В непустой строке он вызывает звуковой сигнал.
- Другие непечатаемые байты, включая Tab, вызывают сигнал: выводится Ctrl+G (`\a`).

Флаг `ISIG` отключён: Ctrl+C, Ctrl+\ и Ctrl+Z поступают как непечатаемые байты и вызывают звуковой сигнал. Сигналы SIGINT, SIGTERM, SIGHUP, SIGQUIT, SIGPIPE и SIGTSTP, отправленные процессу извне, завершают редактор с восстановлением настроек терминала. SIGKILL перехватить нельзя.

## Перенос

Буфер хранит только текущую экранную строку длиной до 40 символов. Когда очередная буква переполняет строку, редактор ищет начало последнего слова, стирает его со старой строки и печатает целиком на следующей. Например, после 33 букв `a`, пробела и `abcdef` следующая буква `g` перенесёт `abcdefg` на новую строку. Ранее завершённые строки больше не редактируются.

Слово длиннее 40 символов приходится разделять после каждого 40-го символа. Программа работает с байтами ASCII, а не с Unicode: русские буквы в UTF-8 не поддерживаются. Для корректного отображения нужна ширина терминала больше 40 столбцов; при меньшей ширине терминал сам переносит вывод раньше редактора.

## Проверка

Ручная проверка: введите `one two   `, нажмите Ctrl+W, затем Ctrl+U и Ctrl+D. Для проверки переноса наберите пример выше. После выхода обычное эхо терминала должно работать.

Автоматические проверки требуют только Python 3 и запускаются в собственных псевдотерминалах:

```sh
make test
```

Проверяются немедленное эхо, исходные коды ERASE/KILL, Ctrl+W, Ctrl+D, сигнал для управляющих байтов, Enter, перенос слова, длинное слово, клавиатурные Ctrl+C/Ctrl+\/Ctrl+Z, восстановление настроек после выхода и внешнего SIGINT, отказ от перенаправленного ввода.

```sh
make clean
```

Удаляет исполняемый файл. Условие без дополнительных методических материалов сохранено в `Task_17.txt`.
