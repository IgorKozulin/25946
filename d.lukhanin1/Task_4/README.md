# Задача 4 — список строк

Программа читает строки, сохраняет их в односвязном списке и после окончания
ввода печатает только первую и последнюю строку. Если строка одна, она выводится
один раз. Если список пуст, ничего не выводится.
Строка, начинающаяся с точки, завершает ввод
и не попадает в список. Точка внутри строки не завершает ввод. EOF также
завершает ввод, поэтому работает перенаправление из файла или канала.

## Сборка и запуск

```sh
cd ~/25946/d.lukhanin1/Task_4
make
./list_strings
```

Введите `first`, затем `middle`, затем `last`, затем `.` — каждое на отдельной
строке. Программа напечатает `first` и `last`. Проверка без ручного ввода:

```sh
printf 'first\nmiddle\nlast\n.\nignored\n' | ./list_strings
printf 'only\n.\n' | ./list_strings
```

Подсказка печатается в stderr; сами сохранённые строки — в stdout.

## Как устроен код

`struct Node` содержит `char *text` и `struct Node *next`. `head` указывает
на первый узел, `tail` — на последний. У пустого списка оба равны `NULL`.

`read_line` читает через `fgets` в буфер из 1024 байт. `strlen` даёт число
прочитанных байт без завершающего `\0`; для хранения нужны ещё один байт и
независимая копия текста. `malloc` создаёт начальную строку, `realloc` расширяет
её до `length + part + 1`, `memcpy` копирует очередную часть вместе с `\0`.
Части длинной строки объединяются до `\n` или EOF: одна строка остаётся одним
узлом, даже если длиннее буфера. Пустая строка тоже сохраняется.

Для полного текста `main` выделяет узел через `malloc(sizeof *node)`. Новый
узел получает строку и `next = NULL`. Для первого узла устанавливается `head`;
для следующих — `tail->next`. Затем обновляется `tail`. Благодаря `tail`
добавление узла не требует прохода по всему списку.

После ввода печатается `head->text`, если список не пуст. `tail->text` печатается
только при `tail != head`: так единственная строка не дублируется. Сравниваются
адреса узлов, а не тексты; одинаковые тексты первой и последней строк выводятся
дважды, если это разные узлы. `free_list` обходит весь список, сначала запоминает
адрес следующего узла, затем освобождает строку и узел.
Читать `node->next` после `free(node)` нельзя.

## Что объяснить на сдаче

- Число строк неизвестно заранее, поэтому узлы и строки создаются динамически.
- Нельзя сохранять адрес временного буфера: следующий `fgets` перезапишет текст.
- `strlen("abc")` равен 3, но для `"abc\0"` нужны 4 байта.
- Добавление в хвост сохраняет порядок ввода. Добавление в голову перевернуло бы его.
- Каждый узел владеет своей строкой; освобождаются обе выделенные области.
- `head == tail` означает, что в непустом списке один узел; его печатаем один раз.
- Переводы строк сохраняются; последняя строка без `\n` выводится без добавления `\n`.
