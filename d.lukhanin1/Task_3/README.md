# Задача 3

```sh
make
./access_file private.txt
```

`make` устанавливает файлу `private.txt` права `600`. При обычном запуске оба
открытия успешны: реальный и эффективный UID совпадают.

Для проверки с одногруппником на общем компьютере сначала убедитесь, что он
может пройти по каталогам до этой папки. Дайте группе право запускать программу:

```sh
chmod 750 access_file
```

Пусть одногруппник запустит `./access_file private.txt`. Его UID не совпадает
с владельцем файла; оба вызова `fopen` должны завершиться ошибкой.

Затем владелец программы включает setuid:

```sh
chmod u+s access_file
```

При повторном запуске одногруппником первый `fopen` должен пройти успешно:
эффективный UID равен владельцу программы и файла. После `setuid(getuid())`
эффективный UID становится UID одногруппника, поэтому второй `fopen` должен
завершиться ошибкой `Permission denied`.

Для возвращения обычных прав после проверки:

```sh
chmod u-s access_file
```
